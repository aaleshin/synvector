## Существенные уточнения

### R1 — Major — Сохранить состояние карточки при рендерах About

**Спека:** 177–178, 636–649, 654–655.
**Источники:** ZO5-1, ZO8-1, CB9-2.

Сейчас `Person` объявлен внутри `About`
(`src/GameLanding.jsx:559–578`). Родитель обновляется при изменениях
видимости; при каждом рендере React получает новый тип `Person`.
Добавляемое состояние ошибки фото будет сбрасываться при перемонтировании.
Стабильный ключ по имени это не исправляет.

**Предлагаемое уточнение:** явно предписать объявление `Person` на уровне
модуля в том же файле, сохранив `person` через props. Это точечная
корректировка, не новый файл или масштабный рефакторинг.

**Приёмка:** заблокировать одно фото, дождаться инициалов, уйти из секции
и вернуться — fallback сохраняется; смена `img` разрешает загрузку нового фото.

### R2 — Major — Согласовать достижимую гарантию без IntersectionObserver

**Спека:** 681–694, 831–833.
**Источник:** CB9-1.

Требование создать iframe сразу при отсутствии API конфликтует с
неизменяемым `useInView`: он без проверки создаёт `IntersectionObserver`
в эффектах существующих компонентов (`src/GameLanding.jsx:65–75`,
использования 560, 670, 699). Защита только нового эффекта загрузки
не устраняет ошибки других компонентов и не обеспечивает работающую
страницу с таким fallback.

Оговорка об ограничении старых анимаций честно описывает границу,
но не делает обещанный сценарий исполнимым.

**Предлагаемое решение требует согласования, а не автоматической правки:**

- Если fallback нужен на реальной странице — разрешить минимальную
  защиту общего `useInView`: без API показывать секции, не создавая observer.
  Это небольшое расширение ранее зафиксированной границы работ.
- Если расширение не допускается — прямо определить API как предпосылку
  поддержки страницы и убрать гарантию работающего fallback всей страницы.
  Локальную защиту загрузчика можно оставить, не выдавая её за совместимость.

**Приёмка при выборе первого варианта:** отключить API до загрузки
страницы; секции видимы, iframe создаётся сразу, исключений нет.
До выбора варианта документ не оставляет однозначной исполнимой гарантии.

## Отклонённое замечание

**DC7-1 — риск невидимости высокой секции из-за threshold 0.2.**

Недостижимая доля пересечения 20% сама по себе не доказывает отсутствие
уведомления: `IntersectionObserver` уведомляет также при изменении
`isIntersecting`, а существующий хук использует именно это поле.
Независимый повторный обзор не подтвердил заявленную причинность.
Менять анимацию на этом основании не предлагается.

Проверка появления команды на коротком viewport 320 × 480 полезна
как дополнительная приёмка, но не доказательство текущего дефекта.
Браузерное воспроизведение в этом ревью не проводилось.
